Multiplication

Basic concept

Multiplication is a way to calculate repeated addition of the same number.

  • The multiplication symbol is x.
  • Example: 3 x 4 = 12
  • It means the same as 4 + 4 + 4.

Easy example

If there are 5 boxes and each box contains 2 pencils, the total number of pencils is 10.

5 x 2 = 10

Multiplication is very useful for calculating groups or repeated amounts.
